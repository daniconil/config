# config
Archivos de configuración.

## Manejo de datos sensibles

Este repositorio solo debe contener valores anonimizados para secretos.

En `.zshrc`, los siguientes valores quedan con placeholder:
- `NGROK_AUTHTOKEN`
- `NVIDIA_API_KEY`

Guarda los valores reales en `~/.zshrc.local` (archivo no versionado por `.gitignore`).
